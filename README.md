# py-fun

A Python project implementing two reusable components: Calculator and Collection.

## Features

### Calculator
- Singleton implementation.
- Addition, subtraction, multiplication and division.
- Prime factorization.
- Numeric values and numeric strings.
- Number words in English, German, Spanish, Russian and Chinese.
- Roman numeral conversion.

### Collection
- Check whether an element exists (`contains`).
- Get collection size (`size`).
- Combine two collections (`zip`).
- Generate power sets (`pset`, `pset_gen`).
- Generate permutations (`perm`, `perm_gen`).

## Requirements
- Python 3
- pip
- GNU Make

## Installation

Clone the repository:

```bash
git clone https://github.com/urmiahirekar25/py-fun.git
cd py-fun
```

Install dependencies:

```bash
make install
```

## Run

```bash
make run
```

Or:

```bash
python main.py
```

## Tests

```bash
make tests
```
